⏱ 밀리초 클릭 타이머

내 컴퓨터 시계와 서버 시계의 오차(skew), 그리고 클릭이 서버에 도착하는 데 걸리는 지연(latency)을 측정해서, 목표한 서버 시각(예: 정각 00.000)에 맞추려면 내 컴퓨터 시계 기준으로 몇 시 몇 분 몇 초 몇 ms에 눌러야 하는지 계산해줍니다. 네트워크는 매번 흔들리기(jitter) 때문에 100% 정확히 맞추는 건 불가능하고, 가장 유리한 타이밍을 알려주는 보조 도구입니다.

1. 실제 사이트와 시간 동기화 측정

대부분의 사이트는 브라우저 보안 정책(CORS) 때문에 이 페이지에서 직접 측정할 수 없습니다. 그래서 같은 컴퓨터에서 실행하는 작은 중계 프로그램(프록시)을 거쳐 측정합니다 — 숫자를 직접 알아낼 필요는 없습니다. 아래 "프록시 처음 실행하기"를 펼쳐 한 번만 설정하세요.

아직 측정하지 않았습니다.
▶ 프록시 처음 실행하기 (최초 1회만, 클릭해서 펼치기)
  1. 이 저장소 폴더에 있는 run_proxy.bat(윈도우) 또는 run_proxy.sh(맥/리눅스)를 더블클릭하세요.
  2. 검은 콘솔 창이 뜨고 "로컬 측정 프록시 실행 중"이 보이면 성공입니다. 측정하는 동안 이 창을 닫지 마세요.
  3. "파이썬이 설치되어 있지 않습니다"라고 뜨면 python.org에서 설치(설치 화면에서 "Add python.exe to PATH" 체크) 후 다시 더블클릭하세요.
  4. 이후 이 페이지로 돌아와 위 "프록시 연결 확인" → "측정 시작" 순서로 누르면 됩니다.
▶ 프록시를 못 쓰는 환경이거나, 이미 오차/지연 값을 알고 있다면 → 수동 입력
