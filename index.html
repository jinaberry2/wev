⏱ 밀리초 클릭 타이머

내 컴퓨터 시계와 서버 시계의 오차(skew), 그리고 클릭이 서버에 도착하는 데 걸리는 지연(latency)을 측정해서, 목표한 서버 시각(예: 정각 00.000)에 맞추려면 내 컴퓨터 시계 기준으로 몇 시 몇 분 몇 초 몇 ms에 눌러야 하는지 계산해줍니다. 네트워크는 매번 흔들리기(jitter) 때문에 100% 정확히 맞추는 건 불가능하고, 가장 유리한 타이밍을 알려주는 보조 도구입니다.

1. 시간 동기화 측정

아직 측정하지 않았습니다.
측정이 안 되거나(CORS 오류 등), 이미 오차/지연 값을 알고 있다면 → 수동 입력

2. 목표 시각 설정 (서버 기준)

3. 계산 결과

먼저 1번에서 측정(또는 수동 입력)을 완료하세요.
